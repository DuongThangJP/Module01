What is CSS?

Cascading Style Sheets (CSS) are used to control the design and layout of a webpage.

With CSS, you can adjust colors, fonts, text sizes, spacing between elements, how items are positioned and arranged, what background images or colors appear, and how a site displays on different devices and screen sizes. CSS provides many additional styling capabilities as well.

Tip: The termcascading refers to the way styles applied to a parent element automatically affect all of its child elements. For example, if you set the body text color to blue, then all headings, paragraphs, and other text inside the body will also appear in blue unless you specify a different style.
